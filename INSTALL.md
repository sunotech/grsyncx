# Installing grsyncx

1. Download `grsyncx-0.4.0-universal-macos.zip` from [GitHub Releases](https://github.com/sunotech/grsyncx/releases).
2. Unzip it and drag `grsyncx.app` into the Applications folder.
3. On first launch, Control-click `grsyncx.app`, choose **Open**, then confirm **Open**.

The current community build is ad-hoc signed and supports both Apple silicon and Intel Macs running macOS 11 or later. A future Developer ID-signed and notarized release can open normally without the first-launch workaround.
